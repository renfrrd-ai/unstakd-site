Features

What you'd get from a hosted platform, on a server you control.

Git push deploys, preview URLs, databases and backups in one dashboard, all running on a single VPS.

Git push deploys

A signed GitHub webhook queues a build for every push to your branch. Dockerfile if you have one, Railpack if you don't.

Failures never go live

The new container has to pass a health check before traffic moves. If the build or the check fails, the current version keeps serving.

Instant rollbacks

Every deploy keeps its image. Rolling back skips the rebuild and is live in about two seconds.

One-click Postgres & Redis

Link a database and DATABASE_URL is injected for you. Nightly backups go to R2, and you can restore with one click.

Domains with HTTPS

Every app gets a free subdomain. To add your own domain, set the DNS record Unstakd shows you; it checks the record and issues the certificate.

Preview deploys

Every pull request gets its own URL at pr-12-app.unstakd.com. It's removed when the PR closes.

Static sites

Vite, Astro, Docusaurus or plain HTML. Static sites are built in a throwaway container and served straight from Caddy, so no app container keeps running.

Logs & metrics

Build logs stream as they happen. Runtime logs come straight from Docker, and each app has 24-hour CPU and memory charts.

Alerts

Failed deploys, crash loops and failed backups go to Discord or any webhook.

How it works

From git push to live in under three minutes.

Every deploy follows the same pipeline: a separate worker runs it, so the dashboard stays fast during long builds.

01

Clone

The webhook is verified and de-duplicated, then the commit is checked out.

02

Build

The framework and port are detected, and the image is tagged with the commit SHA.

03

Check

The container starts on a private network with CPU and memory limits and must answer its health check.

04

Switch

Caddy moves traffic to the new container. The old one stops 30 seconds later.

Zero-downtime redeploys: 400 of 400 requests succeeded during a switch in testing. If any step fails, you get an alert and the old version keeps serving.

CLI

Deploy from your terminal.

A single-file CLI with no dependencies, talking to the token API. Link a repo once, then deploy, follow logs, roll back and manage env vars without opening the dashboard.

  • Tokens are created in the dashboard and stored as hashes only
  • Secrets are encrypted with AES-256-GCM at rest
  • Build logs stream live in your terminal

FAQ

Questions

Can I sign up?

Not yet. Unstakd currently runs one person's projects on one server, and public accounts come later. The full source is on GitHub if you want to run your own.

What can it deploy?

Anything with a Dockerfile, most Node, Python and Go apps through Railpack, and static sites. Each app runs in its own container with CPU and memory limits.

What happens if the server dies?

Database backups go to Cloudflare R2 every night, along with a backup of the platform's own database. Secrets stay encrypted with a key that never touches the database.

Why build another PaaS?

To have one dashboard and one bill instead of side projects spread across hosts with different limits, cold starts and pricing, and to learn how builds, proxies and TLS work along the way.
